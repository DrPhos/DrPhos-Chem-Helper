## Description

DrPhos' Chemistry Pro brings a practical collection of general-chemistry tools together in one app.

Use focused calculators and reference tools for:

- Scientific calculations and significant figures
- Quadratic equations
- Molar mass and elemental analysis
- Ionic compounds and chemical naming
- Stoichiometry and reaction balancing
- Kinetics and half-life calculations
- pH, hydronium, and hydroxide relationships
- Solution concentration calculations

Each tool is organized by topic so you can move quickly from a chemistry problem to the calculation you need. Clear inputs, validation messages, adjustable precision, and formatted results help make calculations easier to follow.

DrPhos' Chemistry Pro is intended as a study and calculation aid. Always follow your instructor's conventions and verify critical work independently.

## App Review notes

All chemistry tools are available in this build. No account, network connection, or external hardware is required. The scientific-calculator decimal regression can be verified by entering `.35 × .1`, which should produce `0.0350` with the default precision.
